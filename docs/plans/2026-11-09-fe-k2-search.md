# FE v2 — Irisan K2: Pencarian Global (Command Palette) — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Kotak pencarian di topbar dan `Ctrl+K`/`Cmd+K` membuka command palette. Palette berisi grup Navigasi (client-side), Pengajuan, User, dan Reviewer (server). Setiap grup hanya berisi apa yang boleh dibaca user itu.

**Architecture:** Grup server diambil dari satu route JSON internal `GET /cari` (`search`). Route itu ada di grup `web` dengan `auth` dan `throttle:60,1`, memakai sesi yang sama dengan halaman, dan bukan API publik atau ber-token (keputusan pemilik W171). Controller: FormRequest → Query `GlobalSearch` → `response()->json`. Setiap grup adalah Query sendiri yang di-scope permission dan BR-SM-07, paling banyak 5 hasil. Klien memakai `fetch` dengan debounce 300 ms dan membatalkan request lama. Palette dibangun dari primitive `Listbox` reka-ui, bukan `Components/ui/command`, karena `UiCommand` menyaring item di klien dan akan menyembunyikan hasil server yang cocok lewat nama ketua atau NIDN.

**Tech Stack:** Laravel 13 / PHP 8.4, spatie/laravel-data, Inertia v3 + Vue 3 + TS, reka-ui (sudah terpasang), @vueuse/core (sudah terpasang), Pest, Vitest, Playwright. **Tanpa dependency baru.**

**Spec:** `docs/requirement-analysis/ux/ia/00_navigation/topbar.md` (scope, permission, perilaku); `docs/design/fe-v2-design.md` §2 (non-tujuan "Pencarian global" yang dibuka oleh irisan ini), §9 K2 ("Query ber-scope BR-SM-07"), §10 E2E-11 (judul = judul Form). DDD BR-SM-07, W47 (`UserPolicy::viewAny`), BR-IAM-11/BR-REV-09 (`reviewers.assign`). `AGENTS.md`. BDD tidak punya skenario pencarian global; jangan mengarang ID skenario.

**Ukuran:** irisan sedang, satu session (Task 1–5).

## Global Constraints

- Gate di setiap commit: `composer run quality` dan `npm run quality`, lewat container `simpas-ci:8.4` dengan `-e DB_PORT=55432 -e DB_PASSWORD=postgres` (PHP host 8.5). Cek `free -m` dulu, jalankan langkah berat satu per satu di bawah watchdog (< 500 MB → kill). Vitest dengan `--maxWorkers=1`.
- Worktree butuh salinan `vendor/` sungguhan dan `.env`; `node_modules` boleh symlink (irisan ini tanpa paket baru).
- Pola LIKE selalu lewat `App\Support\Search\LikePattern::contains()` (E2E-10). PostgreSQL: `whereLike` (ILIKE), bukan `LIKE`.
- Query baru di `app/Queries/Search/`, `implements ChangesNoState`, `AsAction`. Tanpa `@phpstan-ignore`, baseline, cast, inline `@var`, `app()->environment('testing')`. Tanpa `any`/`console.log` di TS.
- Teks UI berbahasa Indonesia, persis: placeholder topbar `Cari halaman, pengajuan, user...`; judul grup `Navigasi`, `Pengajuan`, `User`, `Reviewer`; kosong `Tidak ada hasil.`; gagal `Pencarian gagal. Coba lagi.`; petunjuk < 2 huruf `Ketik minimal 2 huruf untuk mencari pengajuan dan user.`; memuat `Mencari…`; shortcut `⌘K` di macOS, `Ctrl K` di platform lain
- `pending.txt`/`uncovered.txt` tetap `max: 0`; `quality-legacy.txt` tidak bertambah. `resources/js/ziggy.js` jangan diregenerasi.
- Commit satu baris berbahasa Indonesia, tanpa trailer.

## Keputusan (dicatat ke §9 sebagai W171–W173 di Task 5)

- **W171 — Transport.** Pemilik, 2026-11-09: route JSON internal `GET /cari` (grup `web`, `auth`, `throttle:60,1`), bukan partial reload Inertia. Partial reload menjalankan ulang controller halaman yang sedang dibuka di setiap ketukan dan menempelkan `?q=` ke URL-nya.
- **W172 — Scope grup Pengajuan mengikuti `topbar.md`.** Pemilik, 2026-11-09: hanya `submissions.view-own` dan `submissions.view-all`; reviewer tetap memakai Penugasan Review. Bentuknya meniru daftar yang sudah ada:
  - `view-all`: `is_submitted = true`, tanpa laporan anak (`parent_submission_id` null), ditautkan ke `admin.submissions.show`.
  - Selain itu, `view-own`: `SubmissionVisibility::ownedOrJoinedBy` (ketua dan anggota aktif, BR-SM-07), tanpa laporan anak, ditautkan ke `user.submissions.show`.
  - Pencarian mencocokkan judul **Form** atau nama ketua, sama dengan daftar Operator. Label = judul Form (E2E-11 masih terbuka; keduanya berubah bersama).
- **Tanpa indeks trigram (YAGNI).** `ILIKE '%…%'` tanpa indeks `pg_trgm` cukup untuk skala data ITK (ratusan sampai ribuan baris per tabel). Tambahkan indeks GIN `pg_trgm` bila `EXPLAIN` menunjukkan scan lambat.
- **W173 — Tujuan hasil.** User → `admin.users.show`. Reviewer tidak punya halaman detail, jadi tujuannya `admin.reviewers.index?search=<nama>`. Navigasi → `route(item.routeName)`.

## Review Focus

1. **Peneliti mengetik nama/judul pengajuan orang lain** → tidak muncul (BR-SM-07). Dipatok di Task 1.
2. **Operator mencari** → draft yang belum disubmit dan laporan monev anak tidak muncul (meniru `OperatorSubmissionList`). Dipatok di Task 1.
3. **Peneliti tanpa `users.verify`/`users.manage`/`reviewers.assign`** → grup User dan Reviewer kosong, bukan 403 dan bukan bocor. Dipatok di Task 2.
4. **Mengetik cepat atau respons lambat datang terlambat** → hasil lama tidak menimpa hasil istilah terbaru (request lama dibatalkan). Dipatok di Task 3.
5. **Sesi habis (401/419) atau jaringan putus** → palette menampilkan "Pencarian gagal. Coba lagi.", grup Navigasi tetap jalan, tanpa error tak tertangkap. Dipatok di Task 3.
