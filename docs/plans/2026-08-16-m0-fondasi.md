# M0 — Fondasi: Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Membereskan fondasi skema, otorisasi, event, dan storage sehingga M1 (Submission) dan M2 (Review) bisa dibangun di atasnya tanpa menebak.

**Architecture:** Menambah relasi eksplisit yang selama ini ditebak (`form_phase_detail_id`), memindahkan skema dan TRL dari EAV ke kolom sungguhan, lalu memasang lapisan otorisasi (Policy), event, notifikasi, dan storage yang belum ada sama sekali. Semua kode baru lahir di direktori yang otomatis kena PHPStan level 9.

**Tech Stack:** Laravel 13 · PHP 8.4 · PostgreSQL · Pest 4 · `spatie/laravel-model-states` · `spatie/laravel-data` · `spatie/laravel-permission` · `lorisleiva/laravel-actions`

**Spec:** [`docs/design/backend-implementation.md`](../design/backend-implementation.md)

## Global Constraints

- PHP **8.4** — bukan 8.3, bukan 8.5 ([ADR 0003](../adr/0003-pin-php-84-across-environments.md)). Kalau PHP host bukan 8.4, jalankan lewat container (lihat "Menjalankan perintah" di bawah).
- Database **PostgreSQL**. Dilarang menulis SQL berasumsi MySQL. Test tidak boleh pakai SQLite.
- Kode baru di `app/` **selain** `Console`, `Exports`, `Http`, `Mail`, `Models`, `Providers`, `Services` otomatis kena **PHPStan level 9** ([ADR 0001](../adr/0001-two-tier-static-analysis.md)). Dilarang `@phpstan-ignore`, entri baseline, `assert()`, inline `@var`, cast, atau melebarkan tipe untuk membungkam error.
- Status hanya berubah lewat `$submission->status->transitionTo(...)` — tidak pernah `update(['status' => ...])`.
- Penamaan kode **English**, komentar **Bahasa Indonesia**. Sebut kode business rule di komentar (mis. `// BR-SM-07`).
- Setiap task berakhir dengan `composer run quality` hijau sebelum commit.
- Commit memakai Conventional Commits, tanpa trailer co-author.

```php
<?php

use Illuminate\Database\Migrations\Migration;
use Illuminate\Database\Schema\Blueprint;
use Illuminate\Support\Facades\DB;
use Illuminate\Support\Facades\Schema;

return new class extends Migration
{
    public function up(): void
    {
        Schema::table('form_submissions', function (Blueprint $table) {
            $table->foreignId('form_phase_detail_id')->nullable()
                ->constrained('form_phase_details')->nullOnDelete();
            $table->foreignId('submission_period_id')->nullable()
                ->constrained('submission_periods')->nullOnDelete();
            $table->foreignId('scheme_id')->nullable()
                ->constrained('schemes')->nullOnDelete();
            $table->foreignId('trl_id')->nullable()
                ->constrained('technology_readiness_levels')->nullOnDelete();
            $table->smallInteger('last_completed_step')->default(0);
        });

        $this->guardAgainstAmbiguousPhaseDetails();
        $this->backfillPhaseDetail();
        $this->backfillPeriod();
    }

    /**
     * Inferensi lama hanya sah kalau satu Form dipakai tepat satu phase detail.
     * Kalau ada yang ambigu, migration berhenti — tidak menebak.
     */
    private function guardAgainstAmbiguousPhaseDetails(): void
    {
        $ambiguous = DB::select('
            SELECT fs.id, COUNT(DISTINCT fpd.id) AS candidates
            FROM form_submissions fs
            JOIN form_access_controls fac ON fac.form_id = fs.form_id
            JOIN form_phase_details fpd  ON fpd.form_access_control_id = fac.id
            GROUP BY fs.id
            HAVING COUNT(DISTINCT fpd.id) > 1
        ');

        if ($ambiguous !== []) {
            $ids = implode(', ', array_column($ambiguous, 'id'));

            throw new RuntimeException(
                "Backfill dibatalkan: form_submissions berikut punya lebih dari satu "
                ."kandidat form_phase_detail dan harus diselesaikan manual — id: {$ids}"
            );
        }
    }

    private function backfillPhaseDetail(): void
    {
        DB::statement('
            UPDATE form_submissions fs
            SET form_phase_detail_id = sub.detail_id
            FROM (
                SELECT fs2.id AS submission_id, MIN(fpd.id) AS detail_id
                FROM form_submissions fs2
                JOIN form_access_controls fac ON fac.form_id = fs2.form_id
                JOIN form_phase_details fpd  ON fpd.form_access_control_id = fac.id
                GROUP BY fs2.id
            ) AS sub
            WHERE fs.id = sub.submission_id
        ');
    }

    /**
     * Period diturunkan lewat form_phase_detail → submission_date → submission_period.
     * Jalur submission_period_phases TIDAK dipakai: pivot itu tanpa unique constraint,
     * satu FormPhase boleh dimiliki banyak period.
     */
    private function backfillPeriod(): void
    {
        DB::statement('
            UPDATE form_submissions fs
            SET submission_period_id = sd.submission_period_id
            FROM form_phase_details fpd
            JOIN submission_dates sd ON sd.id = fpd.submission_date_id
            WHERE fpd.id = fs.form_phase_detail_id
        ');
    }

    public function down(): void
    {
        Schema::table('form_submissions', function (Blueprint $table) {
            $table->dropConstrainedForeignId('form_phase_detail_id');
            $table->dropConstrainedForeignId('submission_period_id');
            $table->dropConstrainedForeignId('scheme_id');
            $table->dropConstrainedForeignId('trl_id');
            $table->dropColumn('last_completed_step');
        });
    }
};
```

namespace App\Models;

use Illuminate\Database\Eloquent\Factories\HasFactory;

/**

 * @property int $user_profile_id
 * @property string $role
 * @property string $status
 * @property-read FormSubmission $formSubmission
 * @property-read UserProfile $userProfile

class ResearchMember extends Model
{
    use HasFactory;

    public const ROLE_CO_INVESTIGATOR = 'co_investigator';

    public const ROLE_MEMBER = 'member';

    protected $fillable = [
        'form_submission_id',
        'user_profile_id',
        'role',
        'status',
    ];

    /** @return BelongsTo<FormSubmission, $this> */

        return $this->belongsTo(FormSubmission::class);
    }

    /** @return BelongsTo<UserProfile, $this> */
    public function userProfile(): BelongsTo
    {
        return $this->belongsTo(UserProfile::class);
    }

    public function isActive(): bool
    {
        return $this->status === 'active';
    }

    public function canEditOutputs(): bool
    {
        // BR-RO-07 — hanya co_investigator yang boleh tambah/edit luaran.

<?php

namespace App\Support\Concerns;

use Illuminate\Database\Eloquent\Model;

/**
 * BR-FE-14 / BR-SM-12 — mencegah concurrent edit.
 *
 * Controller mengirim `last_updated_at` dari payload; kalau tidak cocok dengan
 * nilai di database berarti ada yang sudah menyimpan duluan.
 */
trait ChecksOptimisticLock
{
    protected function assertNotStale(Model $model, ?string $lastUpdatedAt): void
    {
        $current = $model->updated_at;

        if ($lastUpdatedAt === null || $current === null) {
            abort(409, 'Data sudah diubah pengguna lain. Muat ulang halaman.');
        }

        if (! $current->equalTo($lastUpdatedAt)) {
            abort(409, 'Data sudah diubah pengguna lain. Muat ulang halaman.');
        }
    }
}

<?php

namespace App\Services\Storage;

use Illuminate\Http\UploadedFile;
use Illuminate\Support\Facades\Storage;
use Illuminate\Support\Str;

class S3StorageService implements StorageService
{
    public function __construct(private readonly string $disk = 's3') {}

    public function upload(UploadedFile $file, string $path): FileResult
    {
        $extension = $file->getClientOriginalExtension();
        $name = $extension === '' ? Str::uuid()->toString() : Str::uuid()->toString().'.'.$extension;
        $fullPath = trim($path, '/').'/'.$name;

        Storage::disk($this->disk)->putFileAs(trim($path, '/'), $file, $name);

        return new FileResult($fullPath, $this->getUrl($fullPath));
    }

    public function delete(string $path): void
    {
        Storage::disk($this->disk)->delete($path);
    }

    public function getUrl(string $path, ?int $expiresInMinutes = null): string
    {
        if ($expiresInMinutes === null) {
            return Storage::disk($this->disk)->url($path);
        }

        return Storage::disk($this->disk)->temporaryUrl(
            $path,
            now()->addMinutes($expiresInMinutes),
        );
    }
}

namespace App\Data\Submission;
