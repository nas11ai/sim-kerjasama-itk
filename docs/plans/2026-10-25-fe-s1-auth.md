# FE v2 — Irisan S1: Auth — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Semua layar auth (SHARED-01-01..05, 01-08, 01-09) digambar ulang di atas `AuthLayout` mengikuti wireframe, `Pages/Auth/*` legacy terhapus, dan dua cacat shell sisa F0 ditutup.

**Architecture:** Backend auth sudah ada; irisan ini merapikan props (opsi organisasi aktif, permission undangan) dan menambah satu layar yang belum punya route: **Menunggu Verifikasi** (SHARED-01-05), tujuan pendaratan registrasi mandiri dan login akun `pending`/`rejected` (IAM-VERIFY-01). Tujuan pasca-login diekstrak dari controller ke Query. Flash sesi dijembatani ke flash native Inertia v3 supaya tidak ikut tersimpan di riwayat browser. Komponen bersama `FormField`, `Banner`, `InfoGrid` lahir di irisan ini karena layar auth yang pertama membutuhkannya.

**Tech Stack:** Laravel 13 / PHP 8.4, inertia-laravel v3, spatie/laravel-data, Inertia v3.1.1 + Vue 3 `<script setup>` + TS, shadcn-vue (`Components/ui/`), Ziggy, Pest, Vitest.

**Spec:** `docs/design/fe-v2-design.md` (§4.1–§4.5, §6, baris S1 di §8). Frame: `../simpas-wireframe/screens/SHARED-01-0{1,2,3,4,5,8,9}/screen.js`, state wajib di `../simpas-wireframe/docs/STATE-COVERAGE.md`.

## Global Constraints

- Berkas Vue baru ≤ 250 baris, sasaran < 150; PHP baru ≤ 200, method ≤ 40 baris. Tanpa blok duplikat 6 baris dengan berkas mana pun, **termasuk legacy** — tulis dari wireframe, jangan menyalin halaman lama.
- Baris pertama `<script setup>`: `// Frame: SHARED-01-0X`. Komponen yang menggambar konsekuensi aturan diberi komentar BR (`<!-- BR-IAM-01 — … -->`).
- Identifier Inggris; komentar Indonesia, prosa komentar maks 3 baris. Kosakata UI dari `02_ubiquitous_language.md`.
- TS tanpa `any`/`console.log`/cast; PHPStan tanpa `@phpstan-ignore`, baseline, `assert()`, inline `@var`, cast. `app/Queries/`, `app/Data/` tier strict.
- Tanpa dependency baru. `Components/ui/` dipakai apa adanya (`select`, `checkbox`, `input`, `label`, `button`, `empty`, `alert`).
- Mutasi lewat `useForm`; error dibaca dari `form.errors`. Tanpa `axios`.
- `config/inertia.php` testing `ensure_pages_exist: true` — `->component('Auth/X')` gagal bila berkas halamannya tidak ada; itu kontrak §4.5.
- Gate: `composer run quality` + `npm run quality`. Pest di container `simpas-ci:8.4`, `-e DB_PORT=55432 -e DB_PASSWORD=postgres`; di worktree `vendor/` disalin dan `.env` ikut disalin.
- Commit satu baris, Indonesia, conventional, **tanpa** trailer `Co-Authored-By`.
- Halaman auth hanya membaca props halamannya sendiri, bukan `auth.user` shared. `Auth.user` nullable (carry-over F0) **tidak** dikerjakan di sini: melebarkannya memecah vue-tsc di puluhan halaman legacy → dipindah ke F99.

## Review Focus

1. **Back dari halaman legacy ke halaman v2 setelah sebuah aksi bertoast** tidak boleh memutar ulang toast; partial reload sesudah Back juga tidak. → Task 1 (flash native tidak masuk riwayat; Vitest "tidak menoast saat setup").
2. **Mengetuk menu halaman yang sedang dibuka di mobile** menutup drawer (kunjungan same-URL tidak memicu `navigate`). → Task 2.
3. **Unit organisasi nonaktif tidak boleh ditawarkan** di form registrasi — `RegisterResearcher` menolaknya, dan menawarkannya melanggar anti-tujuan §2 (tombol yang pasti ditolak). Fakultas nonaktif menyembunyikan seluruh prodinya. → Task 4.
4. **User `pending` yang login lewat deep link** tetap dibawa ke URL tujuannya (`intended` menang); login biasa mendarat di layar menunggu verifikasi. Akun `active` dan akun tanpa profil (undangan, operator) yang membuka layar itu dialihkan ke dashboard, bukan melihat layar kosong. → Task 6.
5. **Pesan "Akun Anda tidak aktif"** (BR-IAM-05) harus terbaca sebagai banner penolakan, bukan sekadar teks kecil di bawah field. → Task 3.
