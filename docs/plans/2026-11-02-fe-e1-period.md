## Keputusan penulis rencana (dicatat ke §9 di Task 4)

- **W67** — Label status: `active` "Dibuka", `expired` "Ditutup", `force_closed` "Ditutup Operator", `no_dates` "Belum Bertanggal". "Terjadwal" (frame) tidak ada (lihat atas). Kalimat banner frame pertama disesuaikan: "Periode ditutup otomatis saat **seluruh tenggatnya** terlewat. …", karena gerbangnya `every()` atas semua tanggal, bukan "batas submit".
- **W68** — "Tutup" hanya untuk `active`/`no_dates`. Konfirmasi menyebut jumlah pemilik draft yang akan diberi tahu dan bahwa penutupan tidak bisa dibatalkan dari layar ini.
- **W69** — Tombol "Arsip" (frame, baris Ditutup) tidak dibangun, karena tidak ada layar arsip periode di DDD/frame mana pun. Sebagai gantinya, angka "Pengajuan Masuk" menaut ke Semua Pengajuan bertapis periode (`admin.submissions.index?period=<id>`) bila penonton punya `submissions.view-all`. Angkanya memakai predikat yang sama dengan daftar itu: induk (`parent_submission_id` null) dan `is_submitted = true`.
- **W70** — "Hapus" tidak ada di frame, tapi STATE-COVERAGE menuntut state FE-DELETE-10/11 di frame ini. Setiap baris punya aksi Hapus. Baris terhalang membuka dialog penjelasan (tanpa tombol hapus); baris bebas membuka `ConfirmDialog`.
- **W71** — Buat & sunting berupa dialog di halaman daftar (tanpa frame; §8 hanya menyebut `PeriodIndexPage`). Tidak ada halaman detail periode: semua isinya ada di baris.
- **W72** — Label tanggal teks bebas + `datalist` label yang ada; `SubmissionDateLabel::named()` (firstOrCreate atas nama yang di-trim). Baris tanggal yang dipakai detail tahap terkunci di UI. Backend sudah mempertahankannya (`deleteUnlisted` + `whereDoesntHave('formPhaseDetails')`).
- **W73** — `ExtendSubmissionDates` mengembalikan `DeadlineExtension{extended, notified}`. Periode `is_force_closed` → `notified = 0` tanpa kirim dan tanpa audit "Tenggat periode diperpanjang". Controller mem-flash `deadlineExtended` (jumlah yang diberi tahu) **hanya** bila ada tenggat yang mundur, sehingga "tidak diperpanjang" dan "diperpanjang tanpa draft" (SCH-RULE-13) tidak tertukar.
- **W74** — Filter Tahun = tahun salah satu `SubmissionDate` periode; pilihannya diambil dari tanggal yang ada, terbaru dulu. Filter Status di SQL harus sama persis dengan `displayStatus`, dan test membandingkan keduanya.
- **W75** — Di luar cakupan, dicatat saja: `NotifyActiveSubmissionPeriods`/`PeriodsOpeningToday` masih membaca tanggal pertama sebagai "periode dibuka", sehingga bertentangan dengan gerbang (`SubmissionPeriodOpened` DDD: "Semua active Researcher"). Ini milik irisan notifikasi/C1, bukan layar ini.
