# FE v2 — Irisan F0: Shell & Fondasi — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Menyediakan kerangka yang dipakai semua layar v2: layout aplikasi & auth, sidebar berbasis permission, badge status 8 state, dialog konfirmasi, dan toast flash. Kontrak shared props-nya ikut disiapkan.

**Architecture:** Backend menambah dua Query baca: permission efektif dan flag "punya pengajuan disetujui". Keduanya dibagikan lewat `HandleInertiaRequests`. Label status dikirim backend lewat `SubmissionStatusData`. Frontend menyimpan konfigurasi nav sebagai data murni dan menyaring visibilitasnya dengan fungsi murni yang di-test. Komponen shell di `Components/app/` merangkai primitive shadcn yang sudah ada. Tidak ada halaman legacy yang dihapus di irisan ini.

**Tech Stack:** Laravel 13 / PHP 8.4, spatie/laravel-permission, spatie/laravel-model-states, spatie/laravel-data, Inertia v3, Vue 3 `<script setup>` + TS, shadcn-vue (reka-ui), Ziggy, Pest, Vitest.

**Spec:** `docs/design/fe-v2-design.md` (§3, §4.1–§4.6, §6, baris F0 di §8)

## Global Constraints

- Berkas Vue baru ≤ 250 baris (`hard.vue.file.loc: 250`), berkas PHP baru ≤ 200, method ≤ 40 baris.
- Berkas baru tidak boleh berbagi blok 6 baris dengan berkas lain mana pun, **termasuk legacy**. Jangan menyalin dari `Components/AppSidebar.vue` atau `Layouts/AuthenticatedLayout.vue`.
- Identifier berbahasa Inggris; komentar berbahasa Indonesia, prosa komentar maksimal 3 baris.
- TS: tanpa `any`, tanpa `console.log`, wajib `<script setup lang="ts">`.
- PHPStan: dilarang `@phpstan-ignore`, baseline, `assert()`, inline `@var`, cast. `app/Queries/` dan `app/Data/` masuk tier strict.
- Tanpa dependency baru. Komponen `Components/ui/` dipakai apa adanya.
- Otorisasi tetap di backend; frontend hanya menyembunyikan (§4.4).
- Gate: `composer run quality` dan `npm run quality`. Pest lewat container (AGENTS.md); di worktree, `vendor/` harus disalin, bukan di-symlink, dan `.env` ikut disalin.
- Commit: satu baris, bahasa Indonesia, conventional (`feat(fe): …`), tanpa trailer `Co-Authored-By`.

## Review Focus

1. Super Admin tidak punya permission langsung (hanya role `Super Admin` + `Gate::before`), sehingga sidebar-nya kosong. Dia harus melihat semua menu. → test di Task 1.
2. User dua peran (`researcher` + `reviewer_internal`) harus melihat gabungan grup Pengajuan dan Review, tanpa memilih salah satu. → test di Task 3.
3. Biodata yang disetujui (form `FormType::BIODATA_ID`) tidak boleh membuka menu Monev/Luaran. → test di Task 1.
4. Halaman detail (mis. `user.submissions.show`) harus tetap menyorot menu induknya (Daftar Pengajuan). → test di Task 3.
5. Flash kosong (`null`/`''`) tidak boleh memunculkan toast kosong. Flash yang sama di dua kunjungan berturut-turut tetap muncul dua kali. → test di Task 4.

**Interfaces:**
- Produces:

**Interfaces:**
- Produces: `<ConfirmDialog v-model:open="boolean" title="string" description="string" confirm-label="string" :destructive="boolean" :processing="boolean" @confirm="() => void" />`. Dibangun di atas `Dialog` dari `@/Components/ui/dialog`. Tombol batal menutup (`update:open` false) tanpa `confirm`. Selama `processing`, tombol konfirmasi dinonaktifkan. Nilai `null` atau `''` diabaikan. `workloadWarnings` **tidak** ditangani di sini, karena milik layar penugasan (S4).
